
# Santiago Bernabéu — Interactive Stadium Showcase

A modern, responsive stadium showcase inspired by the renovated Santiago Bernabéu in Madrid, Spain.

This project presents the stadium through a premium digital experience featuring cinematic imagery, architectural highlights, interactive elements and responsive layouts.

## Preview

The showcase includes:

- Cinematic stadium-inspired hero section
- Responsive navigation with mobile menu
- Animated stadium statistics
- Architectural and technology showcase
- Retractable pitch feature
- 360-degree scoreboard feature
- Premium hospitality experiences
- Interactive matchday fixture preview
- Stadium location and visit information
- Interactive FAQ accordion
- Scroll reveal animations
- Responsive layouts for mobile, tablet and desktop

## Getting Started

1. Clone this repository.

```bash
git clone https://github.com/Regalson001/santiago-bernabeu-showcase.git
```

2. Open the project folder.

```bash
cd santiago-bernabeu-showcase
```

3. Open the folder in Visual Studio Code.

```bash
code .
```

4. Open `index.html` using Live Server or your browser.
